# 預設調音檔（第二階段 EQ 頁載入用）

這裡的檔案是依車主的喇叭配置預先寫好的起點，不是量測結果。真正的調音要在車上聽、最好搭配手機 RTA App 與粉紅噪音確認。

## 車主配置（2026-09-30）

| DSP 聲道 | 接法 | 備註 |
| --- | --- | --- |
| CH1 前左 | 左前門中低音 + 左儀表高音（被動分音）+ 中置喇叭音圈 1 | 高音與中低音共用同一組 EQ |
| CH2 前右 | 右前門中低音 + 右儀表高音（被動分音）+ 中置喇叭音圈 2 | 同上 |
| CH3 後左 | 左後門中低音 | 沒有高音單體 |
| CH4 後右 | 右後門中低音 | 沒有高音單體 |
| CH1-OUT + CH2-OUT（RCA） | Pioneer TS-WX130DA 主動式重低音 | 車主確認：吃前左右兩路前級 |

重點限制：

1. 前聲道的 EQ 同時影響高音、中低音與中置。無法只調高音。
2. 重低音吃 CH1 與 CH2 的前級訊號，前組 EQ 在 80 Hz 以下的增減一定會同時改變重低音。CH5 到 CH8 沒有接任何東西。
3. 中置是雙音圈把左右相加，等於把人聲往中間集中；預設檔不另外處理，但若覺得聲場變窄，可考慮日後改接。

## 檔案格式 `dspx8s-preset/1`

```json
{
  "schema": "dspx8s-preset/1",
  "name": "顯示名稱",
  "channelGroups": { "front": [1, 2], "rear": [3, 4] },
  "eq": { "front": [{ "f": 50, "g": 3, "q": 1.2, "note": "說明" }], "rear": [] },
  "levelDb": { "front": 0, "rear": -3 },
  "delayCm": { "1": null, "2": null, "3": null, "4": null },
  "sub": { "lpfHz": 80, "phase": "現場測", "gain": "中" }
}
```

- `eq.<group>` 只列出要動的濾波器；沒列的頻段一律增益 0 dB、頻率與 Q 值維持機器原值。
- 載入時每個濾波器寫到該聲道「頻率最接近」的頻段：F 寫入指定頻率，G 寫入增益，Q 寫入 Q 值。
- `q` 是峰值濾波器的 Q。1.0 到 1.5 是寬而自然的調整，4.3 相當於 1/3 八度圖示等化器的一格。
- `levelDb` 是各組相對主音量的目標，第二階段確認 MIX11 的刻度後才會換算。
- `delayCm` 留 null 等車主量距離填入，見下方。
- `sub` 是重低音本體旋鈕的建議，DSP 不寫入。

## 延時怎麼填

1. 坐在駕駛座，量從耳朵位置到每顆喇叭的直線距離（公分）。前門高音與中低音共用一聲道，取中低音的距離。
2. 最遠的那顆延時填 0，其他填「最遠距離 − 自己的距離」。
3. 第二階段的聲音頁直接輸入公分，程式換算成微秒寫入。

範例（左駕、一般房車，只是示意，不是你的車）：

| 聲道 | 距離 | 延時 |
| --- | --- | --- |
| CH4 後右 | 165 cm | 0 |
| CH2 前右 | 135 cm | 30 cm |
| CH3 後左 | 110 cm | 55 cm |
| CH1 前左 | 80 cm | 85 cm |

## 使用順序

1. 31 段層已在真機確認可寫（2026-09-30）。EQ 頁的層選「31 段（模式區）」，這層才會跟著模式儲存。
2. 重低音已確認接在 CH1+CH2 的前級輸出；前組 80 Hz 以下的調整會一起推到重低音。
3. 量距離後在聲音頁直接輸入公分（程式換算成微秒）。`delayCm` 欄位留給日後自動套用，目前預設不寫延時。
4. 先到模式頁切到要用的槽（例如模式 2），再載入「01 基準」聽 10 分鐘，滿意就按「儲存到模式 2」。其他三組依序存到模式 3、4、5，模式 1 保持原廠平直當備援。
5. 載入預設時程式會自動把另一層不是 0 dB 的頻段歸零（確認框會列出數量），所以不會兩層疊加。連線後若看到黃字提示，也可以在 EQ 頁手動按「歸零另一層增益」。

## 重低音本體建議（Pioneer TS-WX130DA）

- 低通 80 到 100 Hz 之間，先 80。
- 相位：播放 60 到 80 Hz 的低音，坐駕駛座切 0 / 180 度，選聽起來更飽滿的那個。
- 增益先放中間，等 DSP 曲線定了再微調。
